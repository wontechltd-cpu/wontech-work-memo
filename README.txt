WONTECH 일일 업무 메모 v1.1

실행: WONTECH_업무메모-win32-x64 폴더 안의 WONTECH_업무메모.exe
오전 3시를 기준으로 업무 날짜가 자동 변경됩니다.
프로그램을 계속 켜 두어도 오전 3시에 자동으로 오늘 화면으로 이동합니다.
미처리 업무는 주말·월말·연말과 관계없이 다음 날짜에 자동 등록됩니다.
프로그램을 며칠간 열지 않아도 빠진 날짜를 계산해 미처리 업무를 이어갑니다.
날짜별 기록은 리셋하지 않고 컴퓨터에 계속 보관됩니다.
데이터는 해당 컴퓨터에 자동 저장됩니다.
JPG·PDF·인쇄는 현재 선택한 날짜만 출력합니다.

GitHub Actions 자동 빌드:
Actions → Build WONTECH Windows App → 최신 실행 → Artifacts의
WONTECH-업무메모-Windows 파일을 내려받아 압축을 푸세요.
